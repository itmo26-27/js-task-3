# Задание 3. Асинхронность в JavaScript — «Ну, погоди!»

Четыре курицы скатывают яйца по желобам. Вы управляете волком и видите поток сообщений о новых яйцах. Напишите функцию `controlWolf` в `controller.js`, которая поймает все яйца в каждом из трёх раундов. Эмулятор сам запускает поток, двигает яйца и считает результат.

## Начало работы

1. Откройте `index.html` в браузере. Выберите «Разминку» и нажмите «Смотреть демо». На экране видно, как яйца катятся к волку, а шкала под полем показывает, когда можно снова нажать кнопку. Демо воспроизводит записанные нажатия в замедленном темпе.
2. Откройте `controller.js`. Заготовка уже умеет читать поток через `for await…of`.
3. Добавьте управление волком, обновите страницу и нажмите «Запустить». Проверьте все три раунда. Журнал под игровым полем показывает время каждого нажатия, ловли и промаха. Для сдачи достаточно вашего `controller.js`.

На корпусе есть ручное управление. «Игра А» запускает разминку, «Игра Б» — раунд «Смена корзин». Четыре красные кнопки соответствуют четырём положениям корзины. Нажмите «время», чтобы увидеть местное время. Для проверки вашего кода используйте «Запустить».

## Правила

В начале раунда волк держит корзину слева сверху. У каждой позиции своя кнопка — `topLeft`, `topRight`, `bottomLeft`, `bottomRight`. Волк мгновенно переставляет корзину и держит её на месте до следующего нажатия. Первое нажатие доступно сразу. **Между любыми двумя нажатиями должно пройти минимум 400 мс**, даже если это одна и та же кнопка. Раннее нажатие завершает раунд ошибкой.

Яйцо поймано, если в момент падения корзина уже находится у нужного желоба. Несколько яиц могут одновременно катиться по разным желобам. Поток сообщает о них в порядке будущего падения. Во всех раундах можно поймать каждое яйцо.

## Что получает контроллер

| Аргумент | Как использовать |
| --- | --- |
| `eggs` | Асинхронный поток объектов `{ id, basket, catchAt }`. Событие приходит, когда яйцо начинает катиться. `catchAt` — момент падения в миллисекундах от старта раунда. |
| `press(basket)` | Нажать кнопку нужной позиции. Ограничение между нажатиями общее для всех четырёх кнопок. |
| `now()` | Узнать текущее игровое время. |
| `waitUntil(t)` | Дождаться момента `t` по игровым часам через `await`. Если момент уже прошёл, ожидание завершается сразу. |
| `cooldownMs`, `initialBasket` | Минимальный интервал между нажатиями и стартовая позиция волка. |

Игровые часы идут с шагом 10 мс. На каждом шаге эмулятор сначала проверяет падения, затем возобновляет ожидания. Поэтому после `await waitUntil(egg.catchAt)` это яйцо уже упало. Во время ожидания новые сообщения накапливаются. После последнего сообщения поток закрывается, а яйца продолжают катиться.

## Пример

В 0 мс приходит сообщение о том, что яйцо упадёт справа сверху в 800 мс. Вы нажимаете правую верхнюю кнопку. В 100 мс приходит сообщение о том, что яйцо упадёт слева снизу в 1100 мс. В 400 мс кнопки уже доступны, но если сразу переставить корзину, первое яйцо упадёт мимо. В 800 мс эмулятор засчитает первое яйцо. Теперь можно переставить корзину для второго.

## Самопроверка

- «Разминка» — 3 из 3. Волк успевает к одиночным яйцам.
- «Яйца подряд» — 4 из 4. Два яйца подряд попадают в одну корзину.
- «Смена корзин» — 6 из 6. Следующее яйцо может упасть раньше, чем через 400 мс после предыдущего.

При проверке важны результат и способ управления. Контроллер должен принимать решения по сообщениям потока, использовать игровые часы для ожидания и работать при другом порядке корзин с теми же правилами. Расписание раунда и элементы страницы для решения не нужны.
